Plan with Agent A. Execute with Agent B. Monitor everything.

Intake prompts become structured plans, run by a Chrome-based executor that records every move. Launch the control room to queue work, watch telemetry, or pull artifacts.

Launch Control Room Go now
  • Agent A: validates prompts, stores `TaskRecord`, calls GPTPlanner.
  • Agent B: runs browser-use with your Chrome profile and download watchdogs.
  • Control room: FastAPI + JS dashboard with metrics, queue, and artifacts.

Intake

Submit a task via CLI or UI. Agent A creates a `TaskRecord` and enqueues it.

Execution

Agent B loads Chrome, follows the GPT plan, captures screenshots, trace.json, and plan.json.

Monitoring

Open `/control` for live status, metrics from `/api/metrics`, and links to `/exports/run_*`.
